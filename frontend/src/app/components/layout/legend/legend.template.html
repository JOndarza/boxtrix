Areas

Name
Label for the storage space (shelf, drawer, cabinet…)
W · H · D
Width, height and depth of the area in the selected unit
Start
Corner from which boxes are loaded and accessed
Exit
Corridor that must stay clear — blocked from placement (e.g. door path)

Boxes

Name
Product or item identifier
W · H · D
Box dimensions — the algorithm tries all valid rotations
#
Quantity of identical boxes to place
Kg / Lb
Weight per unit — heavier boxes are prioritised for lower positions

Tips

  • Leave Kg empty if weight order doesn't matter
  • Use # to avoid repeating identical rows
  • Import a DXF floor plan to auto-fill area dimensions
